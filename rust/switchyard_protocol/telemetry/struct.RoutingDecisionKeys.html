Struct RoutingDecisionKeys 

Source 
pub struct RoutingDecisionKeys;
Expand description

Attribute keys explaining why a routing algorithm picked its target.

Every value is a bounded label, number, or boolean, except the keys in RoutingDecisionKeys::CONTENT: those carry judge-written free text derived from the request and must be handled like prompt and completion content.
