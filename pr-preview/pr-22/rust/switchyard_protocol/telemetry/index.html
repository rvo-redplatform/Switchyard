Module telemetry 

Source
Expand description

Provider-neutral telemetry vocabulary shared across Switchyard crates.

This module defines the stable string contract for route-selection and Langfuse observations: generic OpenTelemetry attribute keys, Langfuse-native metadata keys, and the allowed values for response origin and call role. It carries only names and values: no instrumentation, exporter, or metric behavior, so any crate can emit or read the same vocabulary without depending on a telemetry backend.
