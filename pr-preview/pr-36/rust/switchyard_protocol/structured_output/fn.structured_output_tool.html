Builds the STRUCTURED_OUTPUT_TOOL definition for a JSON response_format.

format is Chat-shaped: {"type": "json_schema", "json_schema": {...}} or {"type": "json_object"}. Returns Ok(None) for any other type (text, or an unrecognized one). Returns an invalid-request error when the schema cannot be a tool’s parameters, because tool arguments are always an object.
